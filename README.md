# ยืมได้ — ระบบยืม-คืนอุปกรณ์ชุมชน (เวอร์ชัน Backend + Database จริง)

เว็บนี้แบ่งเป็น 2 ส่วน:
- **server/** — Node.js (Express) + MongoDB คือ "สมอง" ของระบบ เก็บข้อมูลจริง
- **public/** — หน้าเว็บ (frontend) ที่เรียกใช้ API จาก server

ต่างจากเวอร์ชันก่อนหน้าตรงที่ข้อมูลทั้งหมด (จำนวนของ, ประวัติการยืม-คืน, รูปบัตรประชาชน) เก็บอยู่ใน **ฐานข้อมูลกลาง** ไม่ใช่ในเบราว์เซอร์ของแต่ละคน ดังนั้นถ้านาย A ยืมของจากมือถือ นาย B ที่เปิดเว็บจากคอมคนละเครื่องจะเห็นจำนวนที่ลดลงด้วย (หน้าเว็บจะดึงข้อมูลใหม่จากเซิร์ฟเวอร์ทุก 8 วินาทีอัตโนมัติ)

---

## 1. เตรียมฐานข้อมูล MongoDB Atlas (ฟรี)

1. ไปที่ https://www.mongodb.com/cloud/atlas/register สมัครบัญชีฟรี
2. สร้าง Cluster แบบ Free tier (M0)
3. ไปที่ **Database Access** สร้างผู้ใช้ + รหัสผ่านสำหรับเชื่อมต่อ (จำไว้ใช้ในขั้นตอนถัดไป)
4. ไปที่ **Network Access** กด Add IP Address เลือก "Allow access from anywhere" (0.0.0.0/0) — สำหรับงานส่งอาจารย์ทำแบบนี้ได้ ถ้าใช้งานจริงควรจำกัดให้แคบกว่านี้
5. ไปที่ **Database > Connect > Drivers** คัดลอก connection string ที่หน้าตาแบบนี้:
   ```
   mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```
   แทน `<username>` `<password>` ด้วยของจริง แล้วเติม `/yeumdai` ต่อท้ายโดเมนก่อน `?` เพื่อกำหนดชื่อฐานข้อมูล เช่น:
   ```
   mongodb+srv://myuser:mypass@cluster0.xxxxx.mongodb.net/yeumdai?retryWrites=true&w=majority
   ```

## 2. รันระบบบนเครื่องตัวเอง (ทดสอบก่อน deploy)

ต้องติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไปก่อน

```bash
cd server
npm install
cp .env.example .env
```

เปิดไฟล์ `server/.env` แล้ววาง connection string ของคุณลงในตัวแปร `MONGODB_URI`

```bash
npm run seed      # ใส่ข้อมูลอุปกรณ์เริ่มต้นลงฐานข้อมูล (รันครั้งเดียวพอ)
npm start         # เริ่มเซิร์ฟเวอร์
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:5000` จะเห็นหน้าเว็บที่ดึงข้อมูลจริงจาก MongoDB

> ลองเปิด 2 แท็บพร้อมกัน ยืมของในแท็บแรก แล้วรอไม่เกิน 8 วินาที แท็บที่สองจะเห็นจำนวนที่ลดลงเองโดยไม่ต้องกด refresh

## 3. Deploy ขึ้นออนไลน์จริง

เว็บนี้มี backend (ต้องรันโปรแกรม Node.js ตลอดเวลา) จึงใช้ hosting แบบ static อย่าง Netlify ไม่ได้แล้ว ต้องใช้บริการที่รัน Node.js ได้ เช่น **Render.com** (มีแผนฟรี):

1. อัปโหลดโปรเจกต์นี้ขึ้น GitHub (สร้าง repo ใหม่ แล้ว push ทั้งโฟลเดอร์ `lending-system`)
2. ไปที่ https://render.com สมัคร/ล็อกอินด้วย GitHub
3. กด **New > Web Service** เลือก repo ที่เพิ่ง push
4. ตั้งค่า:
   - **Root Directory**: `server`
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
5. ไปที่ **Environment** เพิ่มตัวแปร `MONGODB_URI` เป็นค่า connection string เดียวกับที่ใช้ตอนทดสอบในเครื่อง
6. กด Deploy รอสักครู่ Render จะให้ลิงก์แบบ `https://ชื่อโปรเจกต์.onrender.com` มาใช้งานได้ทันที (หน้าเว็บกับ API อยู่ในลิงก์เดียวกัน)
7. รัน seed ครั้งแรกผ่าน Render Shell (แท็บ Shell ในหน้า service) ด้วยคำสั่ง `npm run seed`

> แผนฟรีของ Render จะพักเครื่อง (sleep) เมื่อไม่มีคนเข้าใช้งานสักพัก แล้วปลุกใหม่ตอนมีคนเข้า (ใช้เวลาสัก 30-50 วินาทีครั้งแรก) เหมาะกับงานสาธิต/ส่งอาจารย์ ถ้าจะใช้งานจริงต่อเนื่องควรพิจารณาแผนเสียเงินหรือผู้ให้บริการอื่น

## 4. โครงสร้าง API

| Method | Endpoint | หน้าที่ |
|---|---|---|
| GET | `/api/items` | ดึงรายการอุปกรณ์ทั้งหมด |
| GET | `/api/records` | ดึงประวัติการยืม-คืนทั้งหมด |
| POST | `/api/records` | สร้างรายการยืมใหม่ (multipart/form-data พร้อมไฟล์รูปบัตร) |
| POST | `/api/records/:id/return` | บันทึกการคืนของ |

## 5. ข้อจำกัดที่ควรรู้ (สำหรับใช้งานจริง ไม่ใช่แค่ส่งงาน)

- **อัปเดตแบบ "โพล" ไม่ใช่ realtime แท้** — หน้าเว็บดึงข้อมูลใหม่ทุก 8 วินาที ถ้าอยากให้เห็นการเปลี่ยนแปลงทันทีแบบ push จริงๆ ต้องต่อยอดด้วย **Socket.io** หรือ **Server-Sent Events**
- **ยังไม่มีระบบล็อกอิน/สิทธิ์ผู้ดูแล** — ตอนนี้ใครก็เข้าไปกด "คืนของ" แทนคนอื่นได้ ถ้าใช้งานจริงควรเพิ่มระบบยืนยันตัวตนผู้ดูแลระบบ
- **การแจ้งเตือนยังเป็นการจำลอง** — ปุ่ม "ส่งการแจ้งเตือน" แค่ขึ้นข้อความในหน้าเว็บ ยังไม่ได้ส่งอีเมล/SMS/LINE จริง ต้องต่อบริการอย่าง Nodemailer (อีเมล) หรือ LINE Notify API เพิ่ม
- **รูปบัตรประชาชนเป็นข้อมูลส่วนบุคคลที่ละเอียดอ่อนตาม PDPA** — ควรเข้ารหัสไฟล์ที่เก็บไว้ จำกัดสิทธิ์เข้าถึงเฉพาะผู้ดูแล และมีนโยบายลบข้อมูลเมื่อไม่จำเป็นแล้ว
